# SINTU AI STUDIO

An AI-powered creator platform for planning, producing, managing, and analyzing video content.

## Project status

- Repository initialized.
- 61-agent architecture: planned; implementation and verification pending.
- Responsive web/PWA interface: planned.
- Video generation and publishing integrations: pending official API configuration.

## Principles

- Hindi and multilingual workflows.
- Prompt/topic/script input for each feature.
- Human approval before public publishing or destructive actions.
- Clear separation between estimates and verified analytics.
- Paid APIs disabled until explicitly configured.
